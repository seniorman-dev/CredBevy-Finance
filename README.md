# credbevy

Cred Bevy FinTech App.

Clone this project locally and run onthe go!

1. I implemented pull to refresh functionality just incase an api error occurs so users can easily pull to refresh and get updates.
2. I leveraged GetX to brilliantly handly state management and data flow across the entire UI of the App. I also used GetX's "GetConnect" to handle API calls as opposed to http &  Dio because it's very much efficient.
3. I implemented animations in the app to improve user feel.
4. I ensured optimum performance and scalability of the application
